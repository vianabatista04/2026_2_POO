---

## 📌 Sobre a Disciplina

A disciplina abrange desde os elementos fundamentais do paradigma orientado a objetos até técnicas avançadas de modelagem, coleções, tratamento de exceções e persistência de dados em arquivos. As implementações principais são desenvolvidas em **Python**, utilizando **Java** para exemplos comparativos e aprofundamento de conceitos.

### Conceitos Explorados:

* **Elementos Básicos de POO:** Abstração, cenários/contextos de software, entidades, atributos, encapsulamento e construtores/destrutores (`__init__`, `__del__`).
* **Modelagem e Estrutura:** Introdução ao Diagrama de Classes, membros estáticos, pacotes, módulos, importações e criação/uso de bibliotecas.
* **Pilares de POO & Relações:** Sobrecarga, sobrescrita, herança, agregação, composição, modificadores de acesso/convenções de visibilidade, classes abstratas e interfaces/ABC.
* **Polimorfismo & Binding:** Duck typing em Python vs. tipos estáticos em Java, supertipos e subtipos, e ligações estáticas vs. dinâmicas.
* **Coleções e Generics:** Estruturas de dados em Python (`list`, `set`, `dict`, `tuple`), coleções em Java e tipagem com o módulo `typing`.
* **Tratamento de Exceções:** Blocos `try/except` (Python) e `try/catch` (Java), exceções personalizadas e hierarquia de erros.
* **Manipulação de Arquivos:** Leitura, gravação e atualização em modo texto, além de serialização de objetos com `pickle` (Python) e `Serializable` (Java).

## 🚀 Como Executar

### 🐍 Executando Códigos em Python (Linguagem Principal)

**1. Verificar instalação do Python:**
```bash
python --version
# ou
python3 --version
```

**2. Criar e ativar um ambiente virtual (Opcional, mas recomendado):**
```bash
# Criar o ambiente virtual
python -m venv venv

# Ativar no Linux/macOS
source venv/bin/activate

# Ativar no Windows (PowerShell)
.\venv\Scripts\Activate.ps1
```

**3. Executar um script Python:**
```bash
python caminho/para/o/script.py
```

---

### ☕ Executando Exemplos em Java

**1. Compilar o arquivo Java:**
```bash
javac caminho/para/o/Arquivo.java
```

**2. Executar a classe compilada:**
```bash
java caminho/para/o/Arquivo
```
